PROJECT 02 / COMPUTER VISION

Illegal U-turn Detector

An academic prototype exploring how sensor-triggered image capture and computer vision could help identify vehicles involved in illegal U-turns through license plate recognition.

Project type Academic group project
My role Python & OCR development
Focus Image processing
Python OpenCV Tesseract OCR Raspberry Pi MariaDB

01 / OVERVIEW

Turning captured images into useful data.

The challenge

Detecting a potential traffic violation is only part of the problem. A useful monitoring prototype also needs to capture visual evidence and attempt to identify the vehicle involved.

This project explored a sensor-assisted approach to detecting illegal U-turns and processing vehicle images for license plate text extraction.

The approach

The prototype combined Raspberry Pi hardware and camera-based image capture with Python image processing. OpenCV was used to prepare images and locate potential license plate regions, while Tesseract OCR was used to attempt to extract text.

Captured evidence and related records were also handled through a MariaDB database.

03 / MY CONTRIBUTION

Focused on Python and license plate recognition.

My responsibilities

I worked with one teammate on the Python-based license plate detection and OCR code. The other half of the group focused on developing the website component.

My technical work centred on processing captured images, identifying potential plate regions, and attempting to extract readable text.

Image-processing pipeline

  • Converted captured frames to grayscale.
  • Applied bilateral filtering to reduce noise while preserving edges.
  • Used Canny edge detection to identify prominent boundaries.
  • Examined contours and polygon approximations to find potential plate regions.
  • Passed the cropped region to Tesseract OCR for text extraction.

04 / TECHNICAL CONSIDERATIONS

Working with real-world image limitations.

Finding the plate

Contour-based detection relies on visible edges and suitable image conditions. Plate angle, background detail, lighting, and image quality can affect the result.

Recognising characters

OCR quality depends on the clarity of the cropped plate, character spacing, image resolution, and the contrast between text and background.

Prototype limitations

The approach was a classical image-processing pipeline, not a trained machine-learning detector. More robust localisation, image preprocessing, and accuracy evaluation would be useful areas for further development.
